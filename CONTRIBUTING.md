# Contributing

## Branches

Do not work directly on `main`.

Create a branch for every feature or task.

Branch naming:

- `feature/...`
- `fix/...`
- `docs/...`

Examples:

- `feature/python-auth`
- `feature/go-api`
- `feature/frontend-login`
- `feature/mobile-home`
- `feature/ui-design`

## Workflow

1. Pull the latest `main`
2. Create a new branch
3. Implement the task
4. Commit changes
5. Push the branch
6. Create a Pull Request
7. Review
8. Merge into `main`

## Commits

Use clear commit messages.

Examples:

- `Add user authentication`
- `Create login page`
- `Implement user API`
- `Fix mobile navigation`

## Important

Never commit:

- `.env`
- passwords
- API keys
- tokens
- private credentials
